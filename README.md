# guardx

Website for **GuardX Staffing and Security Solutions Private Limited** — built with Next.js 16 (App Router) and Tailwind CSS v4.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

## Where to edit

- Company details, services, industries, jobs, FAQs, articles: `lib/site.js`
- Pages: `app/` · Shared components: `components/`
- Logo: `public/logo.jpeg` (+ `logo-light.png`, `logo-dark.png`) · Favicon: `app/icon.png`
- Photos: `public/images/` (free stock photos from Pexels)
